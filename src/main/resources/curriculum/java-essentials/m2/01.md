> **Goal:** understand classes and objects and create your own types.
> **Duration:** 90 min

## 1. From variables to objects

Until now we stored a customer like this:
```java
String customerName = "Leyla";
double customerBalance = 500;
String customerIban = "AZ21NABZ...";
```
With 100 customers this becomes chaos. **Object-oriented programming (OOP)** groups related **data** and **behaviour** together.

- A **class** is a blueprint (the drawing of a house).
- An **object** is a concrete thing built from that blueprint (a real house). One class → many objects.

## 2. Your first class

```java
public class BankAccount {
    // fields (state)
    String owner;
    String iban;
    double balance;

    // methods (behaviour)
    void deposit(double amount) {
        balance += amount;
    }

    void withdraw(double amount) {
        balance -= amount;
    }

    void printInfo() {
        System.out.printf("%s (%s): %.2f AZN%n", owner, iban, balance);
    }
}
```

Using it (in another file, `Main.java`):
```java
BankAccount acc = new BankAccount();   // create an object
acc.owner = "Leyla";
acc.iban = "AZ21NABZ0001";
acc.deposit(500);
acc.withdraw(120);
acc.printInfo();                       // Leyla (AZ21NABZ0001): 380.00 AZN

BankAccount other = new BankAccount(); // a second, independent object
other.owner = "Murad";
```

Note: methods inside a class do **not** use `static`. They work with the fields of *this particular* object.

## 3. Constructors

A constructor runs when an object is created with `new`. It sets the initial state.

```java
public class BankAccount {
    String owner;
    String iban;
    double balance;

    BankAccount(String owner, String iban) {
        this.owner = owner;
        this.iban = iban;
        this.balance = 0;
    }

    BankAccount(String owner, String iban, double initialBalance) {
        this(owner, iban);              // call the other constructor
        this.balance = initialBalance;
    }
}

BankAccount acc = new BankAccount("Leyla", "AZ21NABZ0001", 100);
```

- Same name as the class, **no return type**.
- If you write no constructor, Java gives you a default empty one.
- Constructors can be overloaded.

## 4. The `this` keyword

`this` refers to the **current object**. We need it when a parameter has the same name as a field:
```java
this.owner = owner;   // field = parameter
```

## 5. Objects in memory

```java
BankAccount a = new BankAccount("Leyla", "AZ1");
BankAccount b = a;          // same object, two references
b.deposit(50);              // a.balance is also 50
BankAccount c = null;       // no object
// c.deposit(10);           // NullPointerException
```
Variables of class types hold a **reference** (address), not the object itself.

## 6. Step by step: a Product class

```java
public class Product {
    String name;
    double price;
    int stock;

    Product(String name, double price, int stock) {
        this.name = name;
        this.price = price;
        this.stock = stock;
    }

    boolean isAvailable() {
        return stock > 0;
    }

    double totalValue() {
        return price * stock;
    }
}
```
```java
Product[] products = {
    new Product("Laptop", 1800, 3),
    new Product("Mouse", 25, 0),
    new Product("Monitor", 450, 7)
};
for (Product p : products) {
    System.out.println(p.name + " available: " + p.isAvailable());
}
```

## 7. Common mistakes

- ❌ Forgetting `new` → the variable is `null`.
- ❌ `owner = owner;` in the constructor (assigns the parameter to itself). Use `this.owner = owner`.
- ❌ Writing a return type on a constructor: `void BankAccount()` becomes a normal method!
- ❌ Making everything `static`: then all objects share one value.

1. What is the difference between a class and an object?
2. What does `new` do?
3. When do we need `this`?
