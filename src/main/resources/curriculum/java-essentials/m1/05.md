> **Goal:** make decisions in code with `if`, `switch` and the ternary operator.
> **Duration:** 90 min

## 1. `if` / `else`

```java
int balance = 120;
int price = 150;

if (balance >= price) {
    System.out.println("Payment successful");
} else {
    System.out.println("Insufficient funds");
}
```

### `else if` chains

```java
int score = 78;
char grade;
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else if (score >= 70) {
    grade = 'C';
} else if (score >= 60) {
    grade = 'D';
} else {
    grade = 'F';
}
```
Order matters: the first true condition wins.

### Always use braces
```java
if (isVip)
    discount = 0.2;
    freeDelivery = true;   // ❌ runs ALWAYS (not part of the if)
```

## 2. Nested conditions vs guard clauses

```java
// nested (harder to read)
if (user != null) {
    if (user.isActive()) {
        if (balance > 0) { pay(); }
    }
}

// combined ✅
if (user != null && user.isActive() && balance > 0) {
    pay();
}
```

## 3. `switch`

### Classic switch (be careful with `break`)
```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
    default:
        System.out.println("Another day");
}
```
Without `break`, execution "falls through" to the next case.

### Modern arrow switch (Java 14+) ✅
```java
String dayName = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 6, 7 -> "Weekend";
    default -> "Midweek";
};
```
- No `break` needed, no fall-through.
- It is an **expression**: it returns a value.

### `yield` for multi-line cases
```java
double fee = switch (cardType) {
    case "DEBIT" -> 0;
    case "CREDIT" -> {
        double base = amount * 0.02;
        yield Math.max(base, 1);
    }
    default -> throw new IllegalArgumentException("Unknown card: " + cardType);
};
```

Switch works with `int`, `char`, `String`, enums (and patterns in Java 21; see Advanced).

## 4. Ternary operator

```java
String status = balance >= 0 ? "OK" : "OVERDRAFT";
int max = a > b ? a : b;
```
Use it only for **simple** choices. Never nest ternaries.

## 5. Step by step: a delivery price calculator

```java
import java.util.Scanner;

public class Delivery {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        System.out.print("Order total (AZN): ");
        double total = Double.parseDouble(in.nextLine());
        System.out.print("City (baku/sumgait/other): ");
        String city = in.nextLine().trim().toLowerCase();

        double delivery = switch (city) {
            case "baku" -> 3;
            case "sumgait" -> 5;
            default -> 10;
        };
        if (total >= 100) {
            delivery = 0;
        }
        System.out.printf("Delivery: %.2f, to pay: %.2f%n", delivery, total + delivery);
    }
}
```

## 6. Common mistakes

- ❌ `if (x = 5)` → compile error in Java (good!); use `==`.
- ❌ Comparing strings with `==` in conditions.
- ❌ Forgetting `break` in classic switch.
- ❌ Overlapping or wrong order in `else if` chains (`score >= 60` first catches everything).

## 9. Self-check

1. What happens in a classic `switch` without `break`?
2. Rewrite as a ternary: `if (age >= 18) label = "adult"; else label = "minor";`
3. What does a switch **expression** need that a statement does not?

<details><summary>Answers</summary>

1. Fall-through: the following cases also run until a `break`.
2. `label = age >= 18 ? "adult" : "minor";`
3. It must return a value for every possible input (exhaustive, usually with `default`).

</details>

- Prefer teaching the arrow switch as the default; show classic switch for reading legacy code.

## Homework solution idea
```java
double fee; int included;
switch (plan) {
    case "BASIC" -> { fee = 5; included = 100; }
    case "PLUS" -> { fee = 10; included = 500; }
    default -> { fee = 20; included = Integer.MAX_VALUE; }
}
int extra = Math.max(0, minutes - included);
double bill = fee + extra * 0.05;
```
