## 1. Arrays

An array holds a **fixed number** of values of **one type**.

```java
int[] scores = new int[5];          // [0, 0, 0, 0, 0]
scores[0] = 90;
scores[4] = 75;

double[] prices = {12.5, 7.0, 3.99};  // literal
String[] cities = {"Baku", "Ganja", "Sumgait"};

System.out.println(cities.length);   // 3  (no parentheses!)
System.out.println(cities[0]);       // Baku
```

- Indexes start at **0**; the last index is `length - 1`.
- `cities[3]` → `ArrayIndexOutOfBoundsException`.
- Default values: `0`, `0.0`, `false`, `null`.

## 2. Iterating

```java
for (int i = 0; i < prices.length; i++) {
    System.out.println(i + ": " + prices[i]);
}

for (double price : prices) {        // for-each: when you don't need the index
    System.out.println(price);
}
```

## 3. Typical algorithms

```java
static double average(int[] values) {
    int sum = 0;
    for (int v : values) sum += v;
    return (double) sum / values.length;
}

static int indexOfMax(int[] values) {
    int best = 0;
    for (int i = 1; i < values.length; i++) {
        if (values[i] > values[best]) best = i;
    }
    return best;
}
```

## 4. The `Arrays` class

```java
import java.util.Arrays;

int[] a = {5, 2, 9, 1};
Arrays.sort(a);                        // [1, 2, 5, 9]
System.out.println(Arrays.toString(a));
Arrays.fill(a, 0);
int[] copy = Arrays.copyOf(a, 10);
boolean same = Arrays.equals(a, copy);
```
`System.out.println(a)` prints something like `[I@1b6d3586`; use `Arrays.toString(a)`.

## 5. Arrays are references

```java
int[] a = {1, 2, 3};
int[] b = a;      // b points to the SAME array
b[0] = 99;
System.out.println(a[0]);  // 99 !
```
Methods **can** modify the contents of an array passed to them (unlike primitives).

## 6. Two-dimensional arrays

```java
int[][] grid = new int[3][4];    // 3 rows, 4 columns
grid[1][2] = 7;

int[][] seats = {
    {1, 0, 1},
    {0, 0, 1}
};
for (int row = 0; row < seats.length; row++) {
    for (int col = 0; col < seats[row].length; col++) {
        System.out.print(seats[row][col] == 1 ? "X " : "_ ");
    }
    System.out.println();
}
```

## 7. 🏁 Month 1 Project: Grade Book

### Requirements
A console app for a teacher:
1. Ask how many students (max 30).
2. For each student read the **name** and **3 scores** (0–100, validated).
3. Print a table: name, scores, average, letter grade.
4. Print the class average, the best student and the number of students who failed (average < 60).
5. Menu at the end: `1) Search student  2) Show sorted averages  0) Exit`.

### Suggested structure
```java
public class GradeBook {
    static final int SUBJECTS = 3;

    public static void main(String[] args) { ... }
    static int readInt(Scanner in, String prompt, int min, int max) { ... }
    static double average(int[] scores) { ... }
    static char letter(double average) { ... }
    static void printTable(String[] names, int[][] scores) { ... }
    static int bestStudent(int[][] scores) { ... }
}
```

### Expected output (example)
```
Name        S1   S2   S3    Avg  Grade
Leyla       95   88   91   91.3  A
Murad       60   55   70   61.7  D
------------------------------------
Class average: 76.5
Best student: Leyla
Failed: 0
```

### Evaluation checklist
- [ ] Compiles and runs without errors
- [ ] Input validation (no crash on wrong numbers)
- [ ] At least 5 methods with clear names
- [ ] Aligned output with `printf`
- [ ] No duplicated code
