> **Goal:** work with text and read user input from the console.
> **Duration:** 90 min

## 1. Strings

A `String` is a sequence of characters. It is a **class**, not a primitive.

```java
String name = "Anar";
String empty = "";
String greeting = "Hello, " + name + "!";   // concatenation
```

### Strings are immutable
Methods never change the original string; they return a **new** one.
```java
String s = "java";
s.toUpperCase();            // result is lost!
s = s.toUpperCase();        // ✅ "JAVA"
```

## 2. Most used methods

```java
String s = "  Kapital Bank  ";
s.length()                 // 16
s.trim()                   // "Kapital Bank"
s.strip()                  // same, Unicode-aware (prefer)
s.toUpperCase()            // "  KAPITAL BANK  "
"Bank".charAt(0)           // 'B'
"Birbank".indexOf("bank")  // 3   (-1 if not found)
"Birbank".contains("bank") // true
"Birbank".substring(3)     // "bank"
"Birbank".substring(0, 3)  // "Bir"   (end index excluded)
"a,b,c".split(",")         // ["a", "b", "c"]
"java".replace("j", "J")   // "Java"
"".isEmpty()               // true
"  ".isBlank()             // true
"Hi".repeat(3)             // "HiHiHi"
"java".startsWith("ja")    // true
```

## 3. Comparing strings

```java
String a = "java";
String b = new String("java");
System.out.println(a == b);              // false: different objects!
System.out.println(a.equals(b));         // true:  same content ✅
System.out.println("JAVA".equalsIgnoreCase(a)); // true
System.out.println("apple".compareTo("banana")); // negative → "apple" comes first
```
> Rule: **always use `.equals()`** for strings.

## 4. Formatting output

```java
String name = "Leyla";
double balance = 1523.456;
System.out.printf("Customer: %s, balance: %.2f AZN%n", name, balance);
String line = String.format("%-10s|%8.2f", name, balance);
```

| Placeholder | For |
|---|---|
| `%s` | string |
| `%d` | integer |
| `%.2f` | decimal with 2 digits |
| `%n` | new line |
| `%-10s` | left-aligned, width 10 |

## 6. Reading input with Scanner

```java
import java.util.Scanner;

public class Greeter {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        System.out.print("Your name: ");
        String name = in.nextLine();

        System.out.print("Your age: ");
        int age = in.nextInt();

        System.out.printf("Hi %s, in 5 years you will be %d.%n", name, age + 5);
    }
}
```

| Method | Reads |
|---|---|
| `nextLine()` | a whole line |
| `next()` | one word |
| `nextInt()` / `nextDouble()` | a number |

### The famous Scanner trap
```java
int age = in.nextInt();      // leaves "\n" in the buffer
String city = in.nextLine(); // reads the empty rest → ""
```
Fix: call `in.nextLine();` once after `nextInt()`, or read everything with `nextLine()` and convert: `int age = Integer.parseInt(in.nextLine());`

## 7. Common mistakes

- ❌ `==` for strings.
- ❌ Forgetting that `substring(0, 3)` excludes index 3.
- ❌ `charAt(s.length())` → `StringIndexOutOfBoundsException` (last index is `length() - 1`).
- ❌ The `nextInt()` + `nextLine()` trap.

## 8. Exercises

1. Read a full name, print it in upper case, its length and the initials (`Anar Alizada → A.A.`).
2. Read an e-mail and print the username and domain (`anar@gmail.com → anar / gmail.com`).
3. Mask a card number: `4169738812345678 → **** **** **** 5678`.
4. Read a sentence and count how many times the letter `a` appears (without loops: hint `replace`).

## 9. Homework

Write a "receipt printer": read product name, price and quantity (3 times), then print an aligned receipt with `printf`, including the total.

## 10. Self-check

1. Why does `s.toUpperCase();` alone not change `s`?
2. What does `"Birbank".substring(3, 5)` return?
3. Why is `==` wrong for comparing strings?

<details><summary>Answers</summary>

1. Strings are immutable; the method returns a new string that we did not save.
2. `"ba"`
3. `==` compares references (are they the same object), not content.

</details>
