> **Goal:** repeat actions with loops and learn the common loop patterns.
> **Duration:** 90 min

## 1. Why loops?

Printing numbers 1 to 1000 with 1000 `println` lines is impossible to maintain. Loops repeat a block of code.

## 2. `for` loop

```java
for (int i = 1; i <= 5; i++) {
    System.out.println("Payment #" + i);
}
```

| Part | Runs | Example |
|---|---|---|
| initialization | once | `int i = 1` |
| condition | before each iteration | `i <= 5` |
| update | after each iteration | `i++` |

Counting down and steps:
```java
for (int i = 10; i > 0; i--) { ... }
for (int i = 0; i <= 100; i += 10) { ... }
```

## 3. `while` and `do-while`

Use `while` when you **don't know** how many times to repeat.

```java
double balance = 1000;
int months = 0;
while (balance < 2000) {
    balance *= 1.01;     // 1% monthly interest
    months++;
}
System.out.println("Doubled after " + months + " months");
```

`do-while` runs **at least once** (perfect for menus):
```java
Scanner in = new Scanner(System.in);
String choice;
do {
    System.out.println("1) Balance  2) Deposit  0) Exit");
    choice = in.nextLine();
} while (!choice.equals("0"));
```

## 4. `break` and `continue`

```java
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // skip even numbers
    if (i > 7) break;           // stop the loop
    System.out.println(i);      // 1 3 5 7
}
```

## 5. Nested loops

```java
for (int row = 1; row <= 9; row++) {
    for (int col = 1; col <= 9; col++) {
        System.out.printf("%4d", row * col);
    }
    System.out.println();
}
```
The inner loop runs completely for **each** iteration of the outer loop (9 × 9 = 81 times).

## 6. Loop patterns you will use forever

```java
// SUM
int sum = 0;
for (int i = 1; i <= 100; i++) sum += i;           // 5050

// COUNT
int count = 0;
for (int i = 1; i <= 100; i++) if (i % 7 == 0) count++;

// MIN / MAX
int max = Integer.MIN_VALUE;
for (int n : numbers) if (n > max) max = n;        // (arrays: lesson 8)

// SEARCH (stop early)
boolean found = false;
for (int i = 2; i < n; i++) {
    if (n % i == 0) { found = true; break; }
}
```

## 7. Step by step: number guessing game

```java
import java.util.Scanner;

public class GuessGame {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int secret = (int) (Math.random() * 100) + 1;
        int attempts = 0;

        while (true) {
            System.out.print("Guess (1-100): ");
            int guess = Integer.parseInt(in.nextLine());
            attempts++;
            if (guess < secret) {
                System.out.println("Higher ↑");
            } else if (guess > secret) {
                System.out.println("Lower ↓");
            } else {
                System.out.println("Correct! Attempts: " + attempts);
                break;
            }
        }
    }
}
```

## 8. Common mistakes

- ❌ Infinite loop: forgetting `i++` or a condition that never becomes false.
- ❌ Off-by-one: `i < 10` vs `i <= 10`. Always check the first and last iteration.
- ❌ Declaring the accumulator **inside** the loop (`int sum = 0;` resets every time).
- ❌ Changing the loop variable inside a `for` body.

## 9. Exercises

1. Print all even numbers from 1 to 50 in one line.
2. Factorial of N (use `long`).
3. Check if a number is prime.
4. Print all primes up to 100.
5. Reverse an integer: `12345 → 54321` (use `% 10` and `/ 10`).

## 10. Homework

ATM simulator: start balance 500. Menu loop: 1) Check balance 2) Deposit 3) Withdraw (not more than balance, multiple of 10) 0) Exit. Show the number of operations at the end.

## 11. Self-check

1. When do you choose `while` over `for`?
2. How many times does `for (int i = 0; i < 10; i += 3)` run?
3. Difference between `break` and `continue`?

<details><summary>Answers</summary>

1. When the number of iterations is unknown in advance (depends on a condition).
2. 4 times (0, 3, 6, 9).
3. `break` exits the loop; `continue` skips to the next iteration.

</details>

## Teaching tips
- **Tracing tables** are the most effective tool for loops. Make students trace on paper.
- Show how to stop an infinite loop in IntelliJ (red stop button).

## Prime check solution
```java
boolean prime = n > 1;
for (int i = 2; i * i <= n; i++) {
    if (n % i == 0) { prime = false; break; }
}
```
