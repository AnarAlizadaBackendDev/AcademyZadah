> **Goal:** understand what Java is, how a Java program runs, and write and run your first program.
> **Duration:** 90 min · **You need:** a laptop with internet

## 1. Why Java?

Java is one of the most used programming languages in the world. Banks (Kapital Bank, ABB, PASHA), payment systems, airlines, e-commerce and big companies like Google, Amazon and Netflix run huge backend systems on Java.

Java is:

- **Object-oriented**: we model the real world with objects (a `Customer`, an `Order`, a `Payment`).
- **Strongly typed**: the compiler checks types before the program runs, so many bugs are caught early.
- **Platform independent**: the same compiled program runs on Windows, macOS and Linux.
- **Huge ecosystem**: Spring Boot, Hibernate, Kafka clients, thousands of libraries.

## 2. JDK, JRE and JVM

| Term | What it is | Who needs it |
|---|---|---|
| **JVM** (Java Virtual Machine) | Runs compiled Java bytecode | Every machine that runs Java |
| **JRE** (Java Runtime Environment) | JVM + standard libraries | Users who only run programs |
| **JDK** (Java Development Kit) | JRE + compiler (`javac`) + tools | **Developers (us)** |

How a Java program runs:

```
Hello.java  --javac-->  Hello.class (bytecode)  --java (JVM)-->  runs on any OS
```

This is the famous **"write once, run anywhere"**: you compile once to bytecode; the JVM on each operating system translates it to machine code.

## 3. Step by step: install your tools

### Step 1: Install JDK 21
1. Open https://adoptium.net and download **Temurin 21 (LTS)** for your OS.
2. Install with default settings.
3. Open a terminal (Windows: `cmd`, macOS: Terminal) and check:

```bash
java -version
javac -version
```

You should see `21.x.x`. If you see "command not found", restart the terminal or re-install with "Add to PATH" checked.

### Step 2: Install IntelliJ IDEA
1. Download **IntelliJ IDEA Community Edition** (free) from jetbrains.com.
2. Install and open it.
3. **New Project** → Language: Java → Build system: IntelliJ → JDK: 21 → Create.

## 4. Your first program

Create a class `Hello` inside `src`:

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

Click the green ▶ next to `main`. You should see `Hello, Java!` in the console.

### Line by line

| Code | Meaning |
|---|---|
| `public class Hello` | A class named `Hello`. The file **must** be called `Hello.java`. |
| `public static void main(String[] args)` | The **entry point**: the JVM starts here. |
| `System.out.println(...)` | Prints text and moves to a new line. |
| `;` | Every statement ends with a semicolon. |
| `{ }` | Curly braces group code into blocks. |

### Run it from the terminal too

```bash
javac Hello.java   # compile → creates Hello.class
java Hello         # run (no .class extension!)
```

## 5. print vs println, comments

```java
System.out.print("Hello ");    // no new line
System.out.println("world");   // new line after
System.out.println();          // empty line

// single-line comment
/* multi-line
   comment */
```

## 6. Common mistakes

- ❌ File name differs from class name (`hello.java` vs `class Hello`). Java is **case-sensitive**.
- ❌ Missing semicolon `;`. Read the compiler error: it shows the line number.
- ❌ Writing `system.out.println`: it must be `System` with a capital S.
- ❌ Running `java Hello.class`: run `java Hello`.

## Teaching tips
- Installation problems eat time: send install instructions **one day before** the lesson.
- On Windows, the most common issue is `PATH`. Have the Temurin installer option "Set JAVA_HOME" checked.
- Encourage reading compiler errors aloud. This habit pays off for the whole course.
- Do not explain `public static void` deeply yet; say "we will understand each word in month 2".

## Homework check
Any correct output is fine. Look for: correct class/file names, consistent formatting, use of both `print` and `println`.
