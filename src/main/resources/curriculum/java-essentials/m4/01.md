> **Goal:** write concise code with lambdas, functional interfaces and method references.
> **Duration:** 90 min

## 1. From anonymous classes to lambdas

Sorting before Java 8:
```java
products.sort(new Comparator<Product>() {
    @Override
    public int compare(Product a, Product b) {
        return Double.compare(a.price(), b.price());
    }
});
```
With a lambda:
```java
products.sort((a, b) -> Double.compare(a.price(), b.price()));
```
A **lambda** is an anonymous function: `(parameters) -> expression` or `(parameters) -> { statements; }`.

## 2. Syntax variants

```java
() -> System.out.println("hi")
x -> x * 2
(x, y) -> x + y
(String s) -> s.length()
(a, b) -> {
    int sum = a + b;
    return sum * 2;
}
```

## 3. Functional interfaces

A lambda implements an interface with **one abstract method**. Java provides the common ones in `java.util.function`:

| Interface | Method | Shape | Example |
|---|---|---|---|
| `Function<T, R>` | `apply` | T → R | `s -> s.length()` |
| `Predicate<T>` | `test` | T → boolean | `p -> p.price() > 100` |
| `Consumer<T>` | `accept` | T → void | `s -> System.out.println(s)` |
| `Supplier<T>` | `get` | () → T | `() -> LocalDate.now()` |
| `BiFunction<T, U, R>` | `apply` | (T, U) → R | `(a, b) -> a * b` |
| `UnaryOperator<T>` | `apply` | T → T | `s -> s.toUpperCase()` |
| `BinaryOperator<T>` | `apply` | (T, T) → T | `Integer::sum` |

```java
Predicate<String> isLong = s -> s.length() > 5;
Function<String, Integer> length = String::length;
Consumer<String> printer = System.out::println;
Supplier<List<String>> listFactory = ArrayList::new;

isLong.test("Kapital");          // true
length.apply("Birbank");         // 7
```

### Combining
```java
Predicate<Product> expensive = p -> p.price() > 1000;
Predicate<Product> inStock = p -> p.stock() > 0;
Predicate<Product> buyable = expensive.negate().and(inStock);

Function<Double, Double> withVat = x -> x * 1.18;
Function<Double, Double> rounded = x -> Math.round(x * 100) / 100.0;
Function<Double, Double> finalPrice = withVat.andThen(rounded);
```

## 4. Method references

| Kind | Syntax | Lambda equivalent |
|---|---|---|
| static | `Integer::parseInt` | `s -> Integer.parseInt(s)` |
| instance of a parameter | `String::toUpperCase` | `s -> s.toUpperCase()` |
| specific object | `System.out::println` | `x -> System.out.println(x)` |
| constructor | `ArrayList::new` | `() -> new ArrayList<>()` |

## 5. Effectively final

Lambdas can use local variables only if they are not changed:
```java
double rate = 0.18;
Function<Double, Double> vat = x -> x * rate;   // ✅
// rate = 0.2;                                  // ❌ then the lambda would not compile
```

## 6. Step by step: a filter engine

```java
public record Product(String name, String category, double price, int stock) { }

static List<Product> filter(List<Product> products, Predicate<Product> rule) {
    List<Product> result = new ArrayList<>();
    for (Product p : products) {
        if (rule.test(p)) result.add(p);
    }
    return result;
}

filter(products, p -> p.category().equals("Laptop"));
filter(products, p -> p.price() < 50 && p.stock() > 0);
```
Behaviour is passed as a **parameter**. This is the core idea of functional programming.

## 7. Your own functional interface

```java
@FunctionalInterface
public interface FeeCalculator {
    double fee(double amount);
}

Map<String, FeeCalculator> fees = Map.of(
    "CARD", a -> a * 0.01,
    "QR", a -> 0,
    "TRANSFER", a -> Math.max(1, a * 0.005)
);
fees.get("TRANSFER").fee(1000);   // 5.0
```

## 8. Common mistakes

- ❌ Long multi-line lambdas: extract a method and use a method reference.
- ❌ Modifying external variables inside a lambda.
- ❌ Ignoring the existing `java.util.function` interfaces and creating duplicates.
