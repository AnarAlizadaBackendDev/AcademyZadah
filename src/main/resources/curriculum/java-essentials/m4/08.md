## 2. 🏁 Final Project: Personal Expense Tracker

### Functional requirements
1. **Expenses**: id, date, amount, category, description, payment method (`CASH`, `CARD`, `QR`).
2. **Categories**: predefined + user-defined; each with an optional monthly **budget**.
3. CRUD for expenses (add, edit, delete, list).
4. **Search & filter**: by date range, category, amount range, text.
5. **Reports**:
   - total per category for a month
   - top 5 biggest expenses
   - average daily spending
   - budget status: `Food: 320 / 400 AZN (80%)`, warning above 90%
   - month-over-month comparison
6. **Import/export**: CSV import with error report; JSON save/load (Jackson).
7. Console menu that never crashes.

### Technical requirements
- Gradle project, Java 21, packages: `model`, `repository`, `service`, `report`, `io`, `app`.
- Records for value objects, enums, at least one interface with 2 implementations (e.g. `ExpenseRepository`: `InMemory` and `Json`).
- Streams and collectors for reports.
- `Optional` for find methods; custom exceptions.
- **≥ 25 unit tests**, `./gradlew build` green.
- GitHub repo: README with screenshots of the console, ≥ 15 meaningful commits.
