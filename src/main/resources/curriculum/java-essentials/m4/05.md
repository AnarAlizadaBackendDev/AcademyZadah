## 1. Path and Files (NIO.2)

```java
import java.nio.file.*;

Path path = Path.of("data", "contacts.csv");     // data/contacts.csv
path.getFileName();         // contacts.csv
path.toAbsolutePath();
Files.exists(path);
Files.createDirectories(path.getParent());
Files.size(path);
Files.delete(path);
Files.copy(src, dst, StandardCopyOption.REPLACE_EXISTING);
```

## 2. Reading text

```java
String all = Files.readString(path);                 // small files
List<String> lines = Files.readAllLines(path);       // small files
try (Stream<String> stream = Files.lines(path)) {    // big files: lazy
    long errors = stream.filter(l -> l.contains("ERROR")).count();
}
```

## 3. Writing text

```java
Files.writeString(path, "Hello\n");
Files.write(path, List.of("line 1", "line 2"));
Files.writeString(path, "more\n", StandardOpenOption.CREATE, StandardOpenOption.APPEND);

try (BufferedWriter w = Files.newBufferedWriter(path)) {
    w.write("id,name,phone");
    w.newLine();
}
```
Character encoding: Java 18+ uses UTF-8 by default, good for Azerbaijani (ə, ş, ç) and Russian text.

## 4. CSV: import and export

`transactions.csv`:
```
date,iban,type,amount
2026-01-05,AZ01,DEPOSIT,500.00
2026-01-07,AZ01,WITHDRAW,120.50
2026-01-07,AZ02,DEPOSIT,1000
```

```java
record Transaction(LocalDate date, String iban, String type, double amount) {
    static Transaction fromCsv(String line) {
        String[] p = line.split(",");
        if (p.length != 4) throw new IllegalArgumentException("Bad line: " + line);
        return new Transaction(LocalDate.parse(p[0]), p[1], p[2], Double.parseDouble(p[3]));
    }

    String toCsv() {
        return String.join(",", date.toString(), iban, type, String.valueOf(amount));
    }
}

List<Transaction> readAll(Path file) throws IOException {
    try (Stream<String> lines = Files.lines(file)) {
        return lines.skip(1)                     // header
                    .filter(l -> !l.isBlank())
                    .map(Transaction::fromCsv)
                    .toList();
    }
}

void writeSummary(Path file, Map<String, Double> balances) throws IOException {
    List<String> out = new ArrayList<>();
    out.add("iban,balance");
    balances.forEach((iban, bal) -> out.add(iban + "," + String.format("%.2f", bal)));
    Files.write(file, out);
}
```
Note: real CSV can contain commas inside quotes; in production use a library like OpenCSV or Jackson CSV.

## 5. Handling bad lines

```java
List<String> errors = new ArrayList<>();
List<Transaction> ok = new ArrayList<>();
int lineNo = 1;
for (String line : Files.readAllLines(file)) {
    lineNo++;
    try {
        ok.add(Transaction.fromCsv(line));
    } catch (RuntimeException e) {
        errors.add("Line " + lineNo + ": " + e.getMessage());
    }
}
```

## 6. Common I/O exceptions

| Exception | Meaning |
|---|---|
| `NoSuchFileException` | file doesn't exist |
| `AccessDeniedException` | no permission |
| `FileAlreadyExistsException` | creating an existing file |
| `IOException` | parent of all of them |

## 7. Serialization note

Java has built-in object serialization (`ObjectOutputStream`), but it is fragile and insecure. Modern apps store data as **JSON** (Jackson library) or in a **database** (Java Advanced, months 2–3).

## 10. Self-check

1. Which method is better for a 2 GB log file: `readAllLines` or `lines`? Why?
2. Why close streams/readers?
3. Why is `split(",")` not enough for real CSV?

<details><summary>Answers</summary>

1. `Files.lines`: it reads lazily, while `readAllLines` loads everything into memory.
2. To release OS resources (file handles); try-with-resources does it automatically.
3. Values can contain commas inside quotes, escaped quotes, or line breaks.

</details>
