> **Goal:** build reports with reduce, flatMap and Collectors.
> **Duration:** 90 min

## 1. Numeric streams

```java
double total = orders.stream().mapToDouble(Order::amount).sum();
OptionalDouble avg = orders.stream().mapToDouble(Order::amount).average();
DoubleSummaryStatistics stats = orders.stream().mapToDouble(Order::amount).summaryStatistics();
stats.getMin(); stats.getMax(); stats.getAverage(); stats.getCount();
IntStream.rangeClosed(1, 100).sum();     // 5050
```

## 2. reduce

Combine all elements into one value:
```java
int sum = numbers.stream().reduce(0, Integer::sum);
int product = numbers.stream().reduce(1, (a, b) -> a * b);
Optional<String> longest = words.stream().reduce((a, b) -> a.length() >= b.length() ? a : b);
```

## 3. flatMap: flatten nested collections

```java
record Order(String id, List<String> items) { }

List<String> allItems = orders.stream()
        .flatMap(o -> o.items().stream())   // Stream<List<String>> → Stream<String>
        .distinct()
        .toList();
```

## 4. Collectors

```java
import static java.util.stream.Collectors.*;

// group
Map<String, List<Product>> byCategory = products.stream().collect(groupingBy(Product::category));

// group + count
Map<String, Long> countByCategory = products.stream().collect(groupingBy(Product::category, counting()));

// group + sum
Map<String, Double> revenueByCategory = sales.stream()
        .collect(groupingBy(Sale::category, summingDouble(Sale::amount)));

// group + average
Map<String, Double> avgSalary = employees.stream()
        .collect(groupingBy(Employee::department, averagingDouble(Employee::salary)));

// group + max
Map<String, Optional<Employee>> topPaid = employees.stream()
        .collect(groupingBy(Employee::department, maxBy(Comparator.comparingDouble(Employee::salary))));

// group + map to names
Map<String, List<String>> namesByDept = employees.stream()
        .collect(groupingBy(Employee::department, mapping(Employee::name, toList())));

// partition (true/false)
Map<Boolean, List<Employee>> seniors = employees.stream().collect(partitioningBy(e -> e.age() >= 40));

// to map
Map<String, Double> priceByName = products.stream().collect(toMap(Product::name, Product::price));

// join
String csv = names.stream().collect(joining(", ", "[", "]"));

// sorted keys
Map<String, Long> sorted = products.stream()
        .collect(groupingBy(Product::category, TreeMap::new, counting()));
```

## 5. Step by step: sales report

```java
record Sale(String product, String category, String city, double amount, LocalDate date) { }

double totalRevenue = sales.stream().mapToDouble(Sale::amount).sum();

Map<String, Double> byCity = sales.stream()
        .collect(groupingBy(Sale::city, TreeMap::new, summingDouble(Sale::amount)));

String bestProduct = sales.stream()
        .collect(groupingBy(Sale::product, summingDouble(Sale::amount)))
        .entrySet().stream()
        .max(Map.Entry.comparingByValue())
        .map(Map.Entry::getKey)
        .orElse("none");

Map<Month, Double> byMonth = sales.stream()
        .collect(groupingBy(s -> s.date().getMonth(), TreeMap::new, summingDouble(Sale::amount)));
```

## 6. Streams vs loops

| Use streams for | Use loops for |
|---|---|
| filter / map / group / aggregate | complex logic with many branches |
| readable data pipelines | early `return`/`break` with side effects |
| | performance-critical tiny loops |

Readability wins. If a stream needs a comment to be understood, consider a loop.

## 7. Common mistakes

- ❌ `toMap` with duplicate keys → `IllegalStateException`. Provide a merge function: `toMap(k, v, (a, b) -> a)`.
- ❌ Giant single-line pipelines.
- ❌ `parallelStream()` "for speed" without measuring (often slower).

## 10. Self-check

1. What does `flatMap` do?
2. Which collector counts elements per group?
3. What happens with `toMap` when two elements have the same key?

<details><summary>Answers</summary>

1. Maps each element to a stream and flattens all these streams into one.
2. `groupingBy(classifier, counting())`.
3. `IllegalStateException`, unless you pass a merge function.

</details>
