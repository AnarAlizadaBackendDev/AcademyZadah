## 1. StringBuilder

Strings are immutable, so `+` in a loop creates many temporary objects:
```java
String s = "";
for (int i = 0; i < 100_000; i++) s += i;     // ❌ very slow
```
```java
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 100_000; i++) sb.append(i);  // ✅ fast
String result = sb.toString();

sb.insert(0, "start:");
sb.reverse();
sb.deleteCharAt(sb.length() - 1);
```
Also: `String.join(", ", list)` for joining.

## 3. Regular expressions

A regex is a pattern for text.

| Pattern | Matches |
|---|---|
| `\d` | digit |
| `\w` | letter, digit, `_` |
| `\s` | whitespace |
| `.` | any character |
| `[abc]` | a, b or c |
| `[A-Z]` | uppercase letter |
| `+` | 1 or more |
| `*` | 0 or more |
| `?` | 0 or 1 |
| `{4}` | exactly 4 |
| `^` / `$` | start / end |

In Java strings, backslashes are doubled: `"\\d+"`.

```java
boolean isPhone = phone.matches("\\+994(50|51|55|70|77|99)\\d{7}");
boolean isEmail = email.matches("^[\\w.+-]+@[\\w-]+\\.[\\w.]+$");
String digitsOnly = "+994 (50) 123-45-67".replaceAll("\\D", "");   // 994501234567
String[] words = text.split("\\s+");
```

Extracting with `Pattern`/`Matcher`:
```java
Pattern p = Pattern.compile("AZ\\d{2}[A-Z]{4}\\d{20}");
Matcher m = p.matcher(text);
while (m.find()) {
    System.out.println("IBAN found: " + m.group());
}
```

## 4. java.time: dates done right

```java
import java.time.*;
import java.time.format.DateTimeFormatter;

LocalDate today = LocalDate.now();
LocalDate birthday = LocalDate.of(1999, 5, 20);
LocalDateTime now = LocalDateTime.now();
LocalTime openAt = LocalTime.of(9, 0);

LocalDate due = today.plusDays(30).plusMonths(1);
boolean late = today.isAfter(due);
DayOfWeek dow = today.getDayOfWeek();

int age = Period.between(birthday, today).getYears();
long days = java.time.temporal.ChronoUnit.DAYS.between(today, due);
Duration d = Duration.ofMinutes(135);   // PT2H15M
```

Formatting and parsing:
```java
DateTimeFormatter f = DateTimeFormatter.ofPattern("dd.MM.yyyy");
String text = today.format(f);              // 15.10.2026
LocalDate parsed = LocalDate.parse("01.09.2026", f);
```

Time zones:
```java
ZonedDateTime baku = ZonedDateTime.now(ZoneId.of("Asia/Baku"));
Instant timestamp = Instant.now();           // UTC moment: store this in databases
```

Rules:
- `LocalDate` for dates without time (birthday, due date).
- `Instant` / `OffsetDateTime` for exact moments (transactions).
- All java.time classes are **immutable**: `date.plusDays(1)` returns a new date.
- Never use old `Date` / `Calendar` in new code.

## 5. Step by step: loan schedule

```java
LocalDate start = LocalDate.of(2026, 1, 31);
DateTimeFormatter f = DateTimeFormatter.ofPattern("dd MMM yyyy");
for (int i = 1; i <= 6; i++) {
    System.out.println(i + ". " + start.plusMonths(i).format(f));
}
// 28 Feb 2026, 31 Mar 2026, ... (end-of-month handled correctly)
```

## 6. Common mistakes

- ❌ `+` concatenation in big loops.
- ❌ Forgetting to escape `.` in regex (`.` means any char): use `\\.`.
- ❌ `today.plusDays(1);` without assignment.
- ❌ Storing local time for global events (use `Instant`).
