> **Goal:** use `Set` and `Map`, the most important data structures in backend code.
> **Duration:** 90 min

## 1. Set: unique elements

```java
Set<String> tags = new HashSet<>();
tags.add("java");
tags.add("spring");
tags.add("java");          // ignored: already present
tags.size();               // 2
tags.contains("spring");   // O(1)!
```

| Implementation | Order | Speed |
|---|---|---|
| `HashSet` | no order | O(1) |
| `LinkedHashSet` | insertion order | O(1) |
| `TreeSet` | sorted | O(log n) |

Set operations:
```java
Set<String> a = new HashSet<>(Set.of("java", "sql", "git"));
Set<String> b = Set.of("java", "docker");
a.retainAll(b);    // intersection → [java]
a.addAll(b);       // union
a.removeAll(b);    // difference
```

## 2. Map: key → value

```java
Map<String, Double> balances = new HashMap<>();
balances.put("AZ01", 500.0);
balances.put("AZ02", 1200.0);
balances.put("AZ01", 650.0);        // replaces the old value
balances.get("AZ01");               // 650.0
balances.get("AZ99");               // null
balances.getOrDefault("AZ99", 0.0); // 0.0
balances.containsKey("AZ02");       // true
balances.remove("AZ02");
balances.size();
```

### Iterating a map
```java
for (Map.Entry<String, Double> e : balances.entrySet()) {
    System.out.println(e.getKey() + " = " + e.getValue());
}
for (String iban : balances.keySet()) { ... }
for (Double amount : balances.values()) { ... }
balances.forEach((iban, amount) -> System.out.println(iban + ": " + amount));
```

### Very useful methods
```java
map.putIfAbsent(key, value);
map.merge(word, 1, Integer::sum);                       // counting!
map.computeIfAbsent(city, k -> new ArrayList<>()).add(customer);   // grouping!
```

| Implementation | Key order | Speed |
|---|---|---|
| `HashMap` | none | O(1) |
| `LinkedHashMap` | insertion | O(1) |
| `TreeMap` | sorted by key | O(log n) |

## 3. How HashMap works (simplified)

1. `key.hashCode()` → a number → which **bucket** to use.
2. Inside the bucket, `key.equals(...)` finds the exact key.

That's why custom keys **must** implement `equals` and `hashCode` consistently:
```java
record CardKey(String bin, String last4) { }   // records do it for you ✅
```
And keys should be **immutable**: if a key changes after insertion, you can never find it again.

## 4. Step by step: word frequency

```java
String text = "java is great and java is fast and spring is java";
Map<String, Integer> freq = new HashMap<>();
for (String word : text.split("\\s+")) {
    freq.merge(word, 1, Integer::sum);
}
System.out.println(freq);   // {java=3, is=3, and=2, great=1, fast=1, spring=1}
```

## 5. Step by step: grouping

```java
record Customer(String name, String city) { }

List<Customer> customers = List.of(
    new Customer("Leyla", "Baku"), new Customer("Murad", "Ganja"), new Customer("Aysel", "Baku"));

Map<String, List<Customer>> byCity = new TreeMap<>();
for (Customer c : customers) {
    byCity.computeIfAbsent(c.city(), k -> new ArrayList<>()).add(c);
}
// {Baku=[Leyla, Aysel], Ganja=[Murad]}
```

## 6. Choosing the right collection

| Need | Use |
|---|---|
| ordered list, index access | `ArrayList` |
| unique values, fast lookup | `HashSet` |
| unique + sorted | `TreeSet` |
| lookup by key (id, iban) | `HashMap` |
| keys sorted | `TreeMap` |
| keep insertion order | `LinkedHashMap` / `LinkedHashSet` |

## 7. Common mistakes

- ❌ Custom key class without equals/hashCode.
- ❌ Mutable keys.
- ❌ `map.get(key) + 1` when the key is missing → NullPointerException (unboxing null). Use `getOrDefault` or `merge`.
- ❌ Expecting `HashMap` to keep order.

## 10. Self-check

1. What happens if you put the same key twice into a HashMap?
2. Why must keys implement equals and hashCode?
3. Which collection would you use to store unique tags sorted alphabetically?

<details><summary>Answers</summary>

1. The second put replaces the value (and returns the old one).
2. HashMap uses hashCode to find the bucket and equals to find the key; inconsistent implementations break lookups.
3. `TreeSet<String>`.
