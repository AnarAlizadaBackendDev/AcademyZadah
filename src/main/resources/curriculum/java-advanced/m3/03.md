## 1. Identifiers

```java
@Id
@GeneratedValue(strategy = GenerationType.IDENTITY)   // DB identity column (PostgreSQL, MySQL)
private Long id;

@Id
@GeneratedValue(strategy = GenerationType.SEQUENCE, generator = "order_seq")
@SequenceGenerator(name = "order_seq", sequenceName = "orders_id_seq", allocationSize = 50)
private Long id;                                        // batch-friendly

@Id
@GeneratedValue(strategy = GenerationType.UUID)
private UUID id;
```
`SEQUENCE` with `allocationSize` allows Hibernate **batch inserts**; `IDENTITY` disables them.

## 2. Columns

```java
@Column(name = "full_name", nullable = false, length = 120)
private String fullName;

@Column(precision = 19, scale = 4, nullable = false)
private BigDecimal price;                               // money → BigDecimal

@Column(columnDefinition = "TEXT")
private String description;

@Transient
private String temporaryValue;                          // not stored
```

## 3. Enums

```java
@Enumerated(EnumType.STRING)       // ✅ stores "PAID"
private OrderStatus status;
// EnumType.ORDINAL stores 0,1,2: reordering the enum corrupts data ❌
```

## 4. Dates and times

```java
private LocalDate birthDate;            // DATE
private LocalDateTime createdAt;        // TIMESTAMP
private Instant paidAt;                 // TIMESTAMPTZ (UTC moment) ✅ for events
```

Automatic timestamps (Hibernate):
```java
@CreationTimestamp
private Instant createdAt;
@UpdateTimestamp
private Instant updatedAt;
```

## 5. Embeddables: value objects inside an entity

```java
@Embeddable
public class Address {
    private String city;
    private String street;
    private String zip;
}

@Entity
public class Customer {
    @Embedded
    private Address address;           // columns city, street, zip in customers table

    @Embedded
    @AttributeOverrides({
        @AttributeOverride(name = "city", column = @Column(name = "billing_city")),
        @AttributeOverride(name = "street", column = @Column(name = "billing_street")),
        @AttributeOverride(name = "zip", column = @Column(name = "billing_zip"))
    })
    private Address billingAddress;
}
```

Money as embeddable:
```java
@Embeddable
public record Money(@Column(name = "amount") BigDecimal amount,
                    @Column(name = "currency") String currency) { }   // records as embeddables (Hibernate 6.2+)
```

## 6. Inheritance strategies

```java
@Entity
@Inheritance(strategy = InheritanceType.SINGLE_TABLE)
@DiscriminatorColumn(name = "type")
public abstract class Payment { @Id Long id; BigDecimal amount; }

@Entity @DiscriminatorValue("CARD")
public class CardPayment extends Payment { String cardMask; }

@Entity @DiscriminatorValue("QR")
public class QrPayment extends Payment { String merchantId; }
```

| Strategy | Tables | Pros | Cons |
|---|---|---|---|
| `SINGLE_TABLE` | one | fast, simple queries | nullable columns |
| `JOINED` | parent + child tables | normalized | joins on every query |
| `TABLE_PER_CLASS` | one per concrete class | | slow polymorphic queries |
| `@MappedSuperclass` | no parent table | share fields (id, createdAt) | no polymorphic queries |

```java
@MappedSuperclass
public abstract class BaseEntity {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY) protected Long id;
    @CreationTimestamp protected Instant createdAt;
    @UpdateTimestamp protected Instant updatedAt;
}
```

## 7. equals/hashCode for entities

Safe approach: based on id, stable hashCode.
```java
@Override
public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof Customer other)) return false;
    return id != null && id.equals(other.id);
}
@Override
public int hashCode() { return getClass().hashCode(); }
```
Avoid Lombok `@Data` on entities.
