> **Goal:** insert, update, delete and query data with SQL.
> **Duration:** 120 min

## 1. DML: Data Manipulation Language

### INSERT
```sql
INSERT INTO customers (full_name, email) VALUES ('Leyla Mammadova', 'leyla@mail.az');

INSERT INTO customers (full_name, email) VALUES
    ('Murad Aliyev', 'murad@mail.az'),
    ('Aysel Huseynova', 'aysel@mail.az');

INSERT INTO customers (full_name, email) VALUES ('Kamran', 'k@mail.az') RETURNING id;
```

### UPDATE
```sql
UPDATE accounts SET balance = balance + 100 WHERE iban = 'AZ21NABZ00000000137010001944';
UPDATE customers SET status = 'BLOCKED' WHERE id IN (5, 8);
```
⚠️ `UPDATE accounts SET balance = 0;` without `WHERE` updates **every row**. Always write the WHERE first.

### DELETE
```sql
DELETE FROM sessions WHERE expires_at < now();
```

### UPSERT
```sql
INSERT INTO exchange_rates (currency, rate) VALUES ('USD', 1.70)
ON CONFLICT (currency) DO UPDATE SET rate = EXCLUDED.rate;
```

## 2. SELECT

```sql
SELECT full_name, email
FROM customers
WHERE status = 'ACTIVE'
ORDER BY full_name ASC
LIMIT 10 OFFSET 20;      -- page 3 with 10 per page
```

Logical order of execution: `FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT`.

## 3. Filtering

```sql
WHERE balance > 1000 AND currency = 'AZN'
WHERE status = 'BLOCKED' OR status = 'CLOSED'
WHERE status IN ('BLOCKED', 'CLOSED')
WHERE balance BETWEEN 100 AND 500
WHERE full_name LIKE 'A%'          -- starts with A
WHERE email ILIKE '%@GMAIL.COM'    -- case-insensitive (PostgreSQL)
WHERE phone IS NULL
WHERE phone IS NOT NULL
WHERE NOT (balance > 0)
```
⚠️ `= NULL` never works: NULL means "unknown". Use `IS NULL`.

## 4. Expressions and functions

```sql
SELECT full_name,
       upper(full_name)                       AS name_upper,
       length(full_name)                      AS name_length,
       balance * 1.7                          AS balance_usd,
       round(balance, 2),
       coalesce(phone, 'no phone')            AS phone,
       date_part('year', age(birth_date))     AS age,
       CASE
           WHEN balance > 10000 THEN 'VIP'
           WHEN balance > 1000 THEN 'GOLD'
           ELSE 'STANDARD'
       END                                    AS segment
FROM customers c JOIN accounts a ON a.customer_id = c.id;
```

Dates:
```sql
SELECT now(), current_date, now() - interval '7 days';
WHERE created_at >= date_trunc('month', now())
```

## 5. DISTINCT

```sql
SELECT DISTINCT currency FROM accounts;
```

## 6. Hands-on (on the sample DB / your shop schema)

Write queries for:
1. All products cheaper than 50, sorted by price descending.
2. Customers registered this month.
3. Orders with status `NEW` older than 2 days.
4. Products whose name contains "phone" (any case).
5. Page 2 of customers (10 per page), sorted by name.
6. Mark all orders older than 30 days with status `NEW` as `CANCELLED`.
7. Customers without a phone number.
8. Label products as CHEAP/NORMAL/EXPENSIVE with CASE.

(15 queries in total are provided by the teacher.)
