> **Goal:** understand relational databases and run PostgreSQL locally with Docker.
> **Duration:** 120 min

## 1. Why databases?

Files are fine for small apps, but real systems need:
- **concurrent access** by many users,
- **transactions** (all-or-nothing transfers),
- **queries** (find all payments over 1000 AZN last week),
- **integrity** (no order without a customer),
- durability and backups.

## 2. The relational model

- Data lives in **tables** (relations) with **rows** and **columns**.
- Each row has a **primary key** (unique id).
- Tables link via **foreign keys**.

```
customers                         accounts
┌────┬─────────┬────────────┐     ┌────┬─────────────┬────────┬─────────────┐
│ id │ name    │ phone      │     │ id │ customer_id │ iban   │ balance     │
├────┼─────────┼────────────┤     ├────┼─────────────┼────────┼─────────────┤
│ 1  │ Leyla   │ +99450...  │◀────│ 10 │ 1           │ AZ01.. │ 1500.00     │
│ 2  │ Murad   │ +99455...  │◀────│ 11 │ 2           │ AZ02.. │ 320.50      │
└────┴─────────┴────────────┘     └────┴─────────────┴────────┴─────────────┘
```

Popular RDBMS: **PostgreSQL**, Oracle (banks), MySQL, MS SQL Server. SQL is ~90% the same everywhere.

## 3. Run PostgreSQL with Docker

```bash
docker run --name pg -e POSTGRES_PASSWORD=secret -e POSTGRES_DB=bank \
  -p 5432:5432 -v pgdata:/var/lib/postgresql/data -d postgres:17
docker ps
docker logs pg
```

`docker-compose.yml` (better):
```yaml
services:
  postgres:
    image: postgres:17
    environment:
      POSTGRES_DB: bank
      POSTGRES_USER: bank
      POSTGRES_PASSWORD: secret
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data
volumes:
  pgdata:
```
```bash
docker compose up -d
docker compose down          # stop (data kept in volume)
```

## 4. Connecting

### psql (command line)
```bash
docker exec -it pg psql -U postgres -d bank
```
```
\l          list databases
\dt         list tables
\d accounts describe table
\q          quit
```

### DBeaver (GUI)
New connection → PostgreSQL → host `localhost`, port `5432`, db `bank`, user/password. IntelliJ Ultimate's Database tool works the same.

## 5. Databases, schemas, users

```sql
CREATE DATABASE shop;
CREATE USER app_user WITH PASSWORD 'strong-password';
GRANT CONNECT ON DATABASE shop TO app_user;
CREATE SCHEMA billing;
```
Rule: applications connect with a **limited user**, never as superuser.

## 6. First queries

```sql
CREATE TABLE customers (
    id    BIGSERIAL PRIMARY KEY,
    name  VARCHAR(100) NOT NULL,
    phone VARCHAR(20) UNIQUE
);

INSERT INTO customers (name, phone) VALUES ('Leyla', '+994501112233');
INSERT INTO customers (name, phone) VALUES ('Murad', '+994551112233');

SELECT * FROM customers;
SELECT name FROM customers WHERE phone LIKE '+99450%';
```
