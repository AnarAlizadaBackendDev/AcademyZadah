> **Goal:** summarise data with GROUP BY and write advanced queries with subqueries, CTEs and window functions.
> **Duration:** 120 min

## 1. Aggregate functions

```sql
SELECT count(*), count(phone), sum(balance), avg(balance), min(balance), max(balance)
FROM accounts;
```
`count(column)` skips NULLs; `count(*)` counts rows.

## 2. GROUP BY and HAVING

```sql
SELECT currency, count(*) AS accounts, sum(balance) AS total
FROM accounts
GROUP BY currency
HAVING sum(balance) > 100000      -- filter GROUPS (WHERE filters rows)
ORDER BY total DESC;
```
Rule: every column in SELECT must be in GROUP BY or inside an aggregate.

```sql
-- revenue per month
SELECT date_trunc('month', created_at) AS month, sum(total) AS revenue
FROM orders
WHERE status = 'PAID'
GROUP BY 1
ORDER BY 1;
```

## 3. Subqueries

```sql
-- products more expensive than average
SELECT name, price FROM products
WHERE price > (SELECT avg(price) FROM products);

-- customers who ordered in the last week
SELECT full_name FROM customers
WHERE id IN (SELECT customer_id FROM orders WHERE created_at > now() - interval '7 days');

-- EXISTS (often faster, stops at first match)
SELECT c.full_name FROM customers c
WHERE EXISTS (SELECT 1 FROM orders o WHERE o.customer_id = c.id AND o.total > 1000);
```

## 4. CTE (WITH): readable step-by-step queries

```sql
WITH paid_orders AS (
    SELECT customer_id, sum(total) AS spent
    FROM orders
    WHERE status = 'PAID'
    GROUP BY customer_id
),
segments AS (
    SELECT customer_id,
           CASE WHEN spent > 5000 THEN 'VIP' WHEN spent > 1000 THEN 'GOLD' ELSE 'REGULAR' END AS segment
    FROM paid_orders
)
SELECT segment, count(*) FROM segments GROUP BY segment;
```

## 5. Window functions

Aggregates **without collapsing rows**: `function() OVER (PARTITION BY ... ORDER BY ...)`.

```sql
-- rank products by price inside each category
SELECT name, category_id, price,
       rank()       OVER (PARTITION BY category_id ORDER BY price DESC) AS price_rank,
       row_number() OVER (PARTITION BY category_id ORDER BY price DESC) AS rn
FROM products;

-- top 3 products per category
SELECT * FROM (
    SELECT name, category_id, price,
           row_number() OVER (PARTITION BY category_id ORDER BY price DESC) AS rn
    FROM products
) t WHERE rn <= 3;

-- running balance of an account
SELECT created_at, amount,
       sum(amount) OVER (ORDER BY created_at) AS running_balance
FROM transactions
WHERE account_id = 10;

-- compare with previous month
SELECT month, revenue,
       revenue - lag(revenue) OVER (ORDER BY month) AS diff
FROM monthly_revenue;

-- share of total
SELECT name, price, round(100.0 * price / sum(price) OVER (), 2) AS pct FROM products;
```

| Function | Purpose |
|---|---|
| `row_number()` | 1, 2, 3, … unique |
| `rank()` / `dense_rank()` | rankings with ties |
| `lag()` / `lead()` | previous / next row |
| `sum/avg/count() OVER` | running or partitioned totals |
| `ntile(4)` | quartiles |
