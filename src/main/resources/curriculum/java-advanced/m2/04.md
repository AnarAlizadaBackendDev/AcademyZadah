> **Goal:** combine data from multiple tables with joins.
> **Duration:** 120 min

## 1. Relationship types

| Type | Example | How |
|---|---|---|
| one-to-one | customer ↔ passport | FK + UNIQUE |
| one-to-many | customer → accounts | FK in the "many" table |
| many-to-many | students ↔ courses | **join table** `enrollments(student_id, course_id)` |

```sql
CREATE TABLE enrollments (
    student_id BIGINT REFERENCES students (id),
    course_id  BIGINT REFERENCES courses (id),
    enrolled_at DATE NOT NULL DEFAULT current_date,
    PRIMARY KEY (student_id, course_id)
);
```

## 2. INNER JOIN: only matching rows

```sql
SELECT c.full_name, a.iban, a.balance
FROM customers c
JOIN accounts a ON a.customer_id = c.id;
```
Customers without accounts are **not** shown.

## 3. LEFT JOIN: all rows from the left

```sql
SELECT c.full_name, a.iban
FROM customers c
LEFT JOIN accounts a ON a.customer_id = c.id;
```
Customers without accounts appear with `NULL` iban.

Find rows **without** a match (anti-join):
```sql
SELECT c.full_name
FROM customers c
LEFT JOIN accounts a ON a.customer_id = c.id
WHERE a.id IS NULL;               -- customers who have no account
```

## 4. RIGHT and FULL JOIN

```sql
RIGHT JOIN   -- all rows from the right table (rarely used; swap tables and use LEFT)
FULL JOIN    -- all rows from both sides
```

```
INNER:  A ∩ B       LEFT: A + matches      FULL: A ∪ B
```

## 5. Joining many tables

```sql
SELECT o.id          AS order_id,
       c.full_name   AS customer,
       p.name        AS product,
       oi.quantity,
       oi.unit_price,
       oi.quantity * oi.unit_price AS line_total
FROM orders o
JOIN customers c   ON c.id = o.customer_id
JOIN order_items oi ON oi.order_id = o.id
JOIN products p    ON p.id = oi.product_id
WHERE o.created_at >= now() - interval '30 days'
ORDER BY o.id;
```

## 6. Self join

```sql
-- employees and their managers in the same table
SELECT e.name AS employee, m.name AS manager
FROM employees e
LEFT JOIN employees m ON m.id = e.manager_id;
```

## 7. Join pitfalls

- ❌ Forgetting the `ON` condition → **cartesian product** (every row × every row).
- ❌ Filtering a LEFT JOIN's right table in `WHERE` turns it into an INNER JOIN:
```sql
LEFT JOIN accounts a ON a.customer_id = c.id
WHERE a.currency = 'USD'              -- ❌ removes customers without accounts
LEFT JOIN accounts a ON a.customer_id = c.id AND a.currency = 'USD'   -- ✅
```
- ❌ Duplicated rows after joining one-to-many (then summing gives wrong totals).
