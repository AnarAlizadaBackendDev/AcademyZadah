> **Goal:** authenticate users stored in the database with hashed passwords.
> **Duration:** 120 min

## 1. User model

```sql
CREATE TABLE users (
    id            BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    email         VARCHAR(160) NOT NULL UNIQUE,
    password_hash VARCHAR(100) NOT NULL,
    role          VARCHAR(20) NOT NULL,
    enabled       BOOLEAN NOT NULL DEFAULT TRUE,
    failed_logins INT NOT NULL DEFAULT 0,
    locked_until  TIMESTAMPTZ,
    created_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

## 2. UserDetailsService

```java
@Service
public class DbUserDetailsService implements UserDetailsService {
    private final UserRepository users;

    public DbUserDetailsService(UserRepository users) { this.users = users; }

    @Override
    public UserDetails loadUserByUsername(String email) {
        User u = users.findByEmailIgnoreCase(email)
                .orElseThrow(() -> new UsernameNotFoundException("Bad credentials"));   // don't reveal which part is wrong
        return new AppUserPrincipal(u.getId(), u.getEmail(), u.getPasswordHash(),
                u.isEnabled(), u.isLocked(), List.of(new SimpleGrantedAuthority("ROLE_" + u.getRole())));
    }
}
```
`AppUserPrincipal implements UserDetails` and carries your user id: handy in controllers:
```java
@GetMapping("/api/v1/me")
MeResponse me(@AuthenticationPrincipal AppUserPrincipal me) { ... }
```

## 3. Registration

```java
@Transactional
public UserResponse register(RegisterRequest req) {
    if (users.existsByEmailIgnoreCase(req.email())) throw new EmailTakenException();
    User u = new User(req.email().toLowerCase(), passwordEncoder.encode(req.password()), Role.CUSTOMER);
    return UserResponse.from(users.save(u));
}

public record RegisterRequest(@Email @NotBlank String email,
                              @NotBlank @Size(min = 10, max = 72) String password) { }   // BCrypt max 72 bytes
```
Password policy: length beats complexity rules; check against breached-password lists for extra safety.

## 4. Login endpoint (for token-based APIs)

```java
@PostMapping("/api/v1/auth/login")
TokenResponse login(@Valid @RequestBody LoginRequest req) {
    Authentication auth = authenticationManager.authenticate(
            UsernamePasswordAuthenticationToken.unauthenticated(req.email(), req.password()));
    return tokenService.issue((AppUserPrincipal) auth.getPrincipal());   // JWT in lesson 5
}

@Bean
AuthenticationManager authenticationManager(UserDetailsService uds, PasswordEncoder encoder) {
    var provider = new DaoAuthenticationProvider(encoder);
    provider.setUserDetailsService(uds);
    return new ProviderManager(provider);
}
```

## 5. Brute-force protection

```java
@Component
class LoginAttemptListener {
    @EventListener
    void onFailure(AuthenticationFailureBadCredentialsEvent e) { userService.registerFailure(e.getAuthentication().getName()); }
    @EventListener
    void onSuccess(AuthenticationSuccessEvent e) { userService.resetFailures(e.getAuthentication().getName()); }
}
```
After 5 failures: lock for 15 minutes (`locked_until`), return the **same generic error**. Add IP-based rate limiting at the gateway (month 8). This website's own login uses the same idea.

## 6. Session-based login (server-rendered apps)

For web apps with HTML pages (like this academy site): `formLogin()` + session cookie (HttpOnly, Secure, SameSite). For APIs consumed by mobile apps: tokens (lesson 5).
