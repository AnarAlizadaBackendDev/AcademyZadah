> **Goal:** understand OAuth2 and OpenID Connect and delegate login to an identity provider.
> **Duration:** 120 min

## 1. Why delegate identity?

Building secure login (MFA, password reset, social login, lockouts, audits) is hard. Companies use an **Identity Provider (IdP)**: Keycloak, Auth0, Okta, Azure AD, Google.

## 2. OAuth2 roles

| Role | Example |
|---|---|
| Resource owner | the user |
| Client | mobile app / web frontend |
| Authorization server | Keycloak / Google |
| Resource server | **your Spring API** |

OAuth2 = **authorization** (access tokens to call APIs).
**OpenID Connect (OIDC)** = identity layer on top: adds an **ID token** with user info (who logged in).

## 3. Authorization Code flow with PKCE (the one to use)

```
1. App → browser → IdP /authorize?client_id=..&code_challenge=..
2. User logs in at the IdP (password, MFA, Google...)
3. IdP → redirect back with ?code=XYZ
4. App → IdP /token (code + code_verifier) → access token (+ refresh, + id token)
5. App → Your API with Authorization: Bearer <access token>
6. Your API validates the token with the IdP's public keys (JWKS)
```
Other flows: **Client Credentials** (service-to-service, no user). Deprecated: implicit, password grant.

## 4. Your API as a resource server

```yaml
spring:
  security:
    oauth2:
      resourceserver:
        jwt:
          issuer-uri: http://localhost:8180/realms/shop
```
```java
http.oauth2ResourceServer(o -> o.jwt(Customizer.withDefaults()));
```
Spring downloads the IdP's signing keys from `/.well-known/openid-configuration` and validates tokens automatically.

Mapping Keycloak roles:
```java
JwtAuthenticationConverter rolesConverter() {
    var conv = new JwtAuthenticationConverter();
    conv.setJwtGrantedAuthoritiesConverter(jwt -> {
        Map<String, Object> realm = jwt.getClaim("realm_access");
        List<String> roles = realm == null ? List.of() : (List<String>) realm.get("roles");
        return roles.stream().map(r -> (GrantedAuthority) new SimpleGrantedAuthority("ROLE_" + r.toUpperCase())).toList();
    });
    return conv;
}
```

## 5. Keycloak locally

```yaml
services:
  keycloak:
    image: quay.io/keycloak/keycloak:26.0
    command: start-dev
    environment:
      KC_BOOTSTRAP_ADMIN_USERNAME: admin
      KC_BOOTSTRAP_ADMIN_PASSWORD: admin
    ports: ["8180:8080"]
```
Create realm `shop`, client `shop-web` (public, PKCE), roles `customer`/`admin`, users.

## 6. Login with Google (OAuth2 client)

For server-rendered apps:
```yaml
spring.security.oauth2.client.registration.google:
  client-id: ${GOOGLE_CLIENT_ID}
  client-secret: ${GOOGLE_CLIENT_SECRET}
  scope: openid, profile, email
```
```java
http.oauth2Login(Customizer.withDefaults());
```

## 7. Service-to-service (client credentials)

```java
@Bean
RestClient ordersClient(RestClient.Builder b, OAuth2AuthorizedClientManager manager) {
    var interceptor = new OAuth2ClientHttpRequestInterceptor(manager);
    interceptor.setClientRegistrationIdResolver(req -> "orders-service");
    return b.requestInterceptor(interceptor).build();
}
```
