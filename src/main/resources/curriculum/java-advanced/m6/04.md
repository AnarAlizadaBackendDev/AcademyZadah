> **Goal:** implement authorization with roles, method security and ownership checks.
> **Duration:** 120 min

## 1. Roles vs authorities

- **Authority**: a permission string, e.g. `orders:read`, `products:write`.
- **Role**: a group of authorities, stored as authority with `ROLE_` prefix (`ROLE_ADMIN`).

`hasRole("ADMIN")` checks `ROLE_ADMIN`; `hasAuthority("products:write")` checks the exact string.

Small apps: roles. Bigger apps: fine-grained authorities (permissions) mapped from roles.

## 2. URL-based rules

```java
.authorizeHttpRequests(auth -> auth
    .requestMatchers(HttpMethod.GET, "/api/v1/products/**").permitAll()
    .requestMatchers(HttpMethod.POST, "/api/v1/products/**").hasAuthority("products:write")
    .requestMatchers("/api/v1/admin/**").hasRole("ADMIN")
    .requestMatchers("/api/v1/reports/**").hasAnyRole("ADMIN", "MANAGER")
    .anyRequest().authenticated())
```

## 3. Method security

```java
@Configuration
@EnableMethodSecurity
class MethodSecurityConfig { }

@Service
public class ProductAdminService {
    @PreAuthorize("hasAuthority('products:write')")
    public ProductResponse create(CreateProductRequest r) { ... }

    @PreAuthorize("hasRole('ADMIN')")
    public void delete(Long id) { ... }
}
```
Method security protects the **service**, even if a new controller forgets URL rules.

## 4. Ownership checks

```java
@PreAuthorize("@orderSecurity.isOwner(#orderId, authentication)")
public OrderResponse get(Long orderId) { ... }

@Component("orderSecurity")
class OrderSecurity {
    boolean isOwner(Long orderId, Authentication auth) {
        var me = (AppUserPrincipal) auth.getPrincipal();
        return orders.existsByIdAndCustomerUserId(orderId, me.getId());
    }
}
```
Or explicitly in the query (simpler, also efficient):
```java
public OrderResponse getForCustomer(Long orderId, Long userId) {
    return orders.findByIdAndCustomerUserId(orderId, userId)
                 .map(OrderResponse::from)
                 .orElseThrow(() -> new NotFoundException("order", orderId));   // 404, not 403: don't reveal existence
}

@PostAuthorize("returnObject.customerId() == authentication.principal.customerId")
public OrderResponse load(Long id) { ... }
```

Admins:
```java
boolean canView(Long orderId, Authentication auth) {
    return hasRole(auth, "ADMIN") || isOwner(orderId, auth);
}
```

## 5. Testing authorization

```java
@WebMvcTest(OrderController.class)
@Import(SecurityConfig.class)
class OrderSecurityTest {
    @Autowired MockMvc mvc;

    @Test
    void anonymousGets401() throws Exception {
        mvc.perform(get("/api/v1/orders/1")).andExpect(status().isUnauthorized());
    }

    @Test
    @WithMockUser(roles = "CUSTOMER")
    void customerCannotDeleteProducts() throws Exception {
        mvc.perform(delete("/api/v1/products/1").with(csrf())).andExpect(status().isForbidden());
    }
}
```
Write a test for **every** access rule: they are business requirements.

## 6. Hands-on
