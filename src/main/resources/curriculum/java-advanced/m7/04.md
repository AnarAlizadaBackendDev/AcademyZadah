> **Goal:** test Spring layers in isolation with test slices.
> **Duration:** 120 min

## 1. Full context vs slices

| Annotation | Loads | Use for |
|---|---|---|
| `@SpringBootTest` | everything | integration tests |
| `@WebMvcTest` | MVC layer: controllers, advice, filters, security | controller logic, JSON, validation, status codes |
| `@DataJpaTest` | JPA, repositories, Flyway | queries, mappings |
| `@JsonTest` | Jackson | DTO serialization |
| `@RestClientTest` | RestClient + `MockRestServiceServer` | HTTP clients |

Slices are faster and focused.

## 2. @WebMvcTest

```java
@WebMvcTest(ProductController.class)
@Import(SecurityConfig.class)
class ProductControllerTest {

    @Autowired MockMvc mvc;
    @MockitoBean CatalogService catalog;          // Spring Boot 3.4+ (older: @MockBean)

    @Test
    void returnsProduct() throws Exception {
        when(catalog.get(1L)).thenReturn(new ProductResponse(1L, "SKU1", "Laptop", new BigDecimal("2400"), "Laptops"));

        mvc.perform(get("/api/v1/products/1"))
           .andExpect(status().isOk())
           .andExpect(jsonPath("$.name").value("Laptop"))
           .andExpect(jsonPath("$.price").value(2400));
    }

    @Test
    @WithMockUser(roles = "ADMIN")
    void validationErrorReturns400() throws Exception {
        mvc.perform(post("/api/v1/products").with(csrf())
                .contentType(MediaType.APPLICATION_JSON)
                .content("""
                        {"sku": "", "name": "X", "price": -1}
                        """))
           .andExpect(status().isBadRequest())
           .andExpect(jsonPath("$.code").value("VALIDATION_FAILED"))
           .andExpect(jsonPath("$.errors.sku").exists())
           .andExpect(jsonPath("$.errors.price").exists());
    }

    @Test
    void notFoundIsMappedTo404() throws Exception {
        when(catalog.get(99L)).thenThrow(new NotFoundException("product", 99L));
        mvc.perform(get("/api/v1/products/99"))
           .andExpect(status().isNotFound())
           .andExpect(jsonPath("$.code").value("NOT_FOUND"));
    }
}
```
Spring Boot 3.4+ also offers `MockMvcTester` with AssertJ-style assertions.

## 3. @DataJpaTest

```java
@DataJpaTest
@AutoConfigureTestDatabase(replace = AutoConfigureTestDatabase.Replace.NONE)   // use real DB config (Testcontainers next lesson)
class ProductRepositoryTest {

    @Autowired ProductRepository products;
    @Autowired TestEntityManager em;

    @Test
    void findsCheapProductsInCategory() {
        Category c = em.persist(new Category("Mice"));
        em.persist(new Product("M1", "Cheap mouse", new BigDecimal("15"), c));
        em.persist(new Product("M2", "Pro mouse", new BigDecimal("150"), c));
        em.flush();
        em.clear();                                   // force real SELECTs

        var result = products.findByCategoryNameAndPriceLessThan("Mice", new BigDecimal("50"));

        assertThat(result).extracting(Product::getSku).containsExactly("M1");
    }
}
```
Each test runs in a transaction rolled back at the end.

## 4. @JsonTest

```java
@JsonTest
class OrderResponseJsonTest {
    @Autowired JacksonTester<OrderResponse> json;

    @Test
    void serializesMoneyAsString() throws Exception {
        var content = json.write(new OrderResponse(1L, "PAID", new BigDecimal("10.50")));
        assertThat(content).extractingJsonPathStringValue("$.total").isEqualTo("10.50");
    }
}
```

## 5. @RestClientTest

```java
@RestClientTest(RatesClient.class)
class RatesClientTest {
    @Autowired RatesClient client;
    @Autowired MockRestServiceServer server;

    @Test
    void parsesRate() {
        server.expect(requestTo(containsString("/rates?from=USD&to=AZN")))
              .andRespond(withSuccess("""
                      {"rate": 1.70}""", MediaType.APPLICATION_JSON));
        assertThat(client.rate("USD", "AZN")).isEqualByComparingTo("1.70");
    }
}
```

## 6. Context caching

Spring caches application contexts between tests with the same configuration. Many different `@MockitoBean` combinations → many contexts → slow suites. Keep configurations consistent; prefer base test classes.

## 7. Hands-on

1. `@WebMvcTest` for products and orders controllers: happy paths, validation, error mapping, security (401/403).
2. `@DataJpaTest` for custom queries and specifications.
3. `@JsonTest` for money/date formats.
4. `@RestClientTest` for the rates client including a 500 error.
