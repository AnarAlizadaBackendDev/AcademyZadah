## 1. Lifecycle

```java
    @BeforeAll static void beforeAll() { }      // once per class

    @AfterEach void tearDown() { }
    @AfterAll static void afterAll() { }

```

## 2. AssertJ: fluent assertions

```java
import static org.assertj.core.api.Assertions.*;

assertThat(order.total()).isEqualByComparingTo("89.90");
assertThat(order.getStatus()).isEqualTo(OrderStatus.NEW);
assertThat(products).hasSize(3)
                    .extracting(Product::getName)
                    .containsExactly("Laptop", "Mouse", "Monitor");
assertThat(customer.getEmail()).isNotBlank().endsWith("@mail.az");
assertThatThrownBy(() -> account.withdraw(new BigDecimal("1000")))
        .isInstanceOf(InsufficientFundsException.class)
        .hasMessageContaining("1000");
assertThat(result).usingRecursiveComparison().ignoringFields("id", "createdAt").isEqualTo(expected);
```
Much better failure messages than `assertEquals`.

## 3. Parameterized tests

```java
@ParameterizedTest
@CsvSource({
    "0,      0.00",
    "99.99,  0.00",
    "100,    5.00",
    "1000,  50.00"
})
void discount(BigDecimal orderTotal, BigDecimal expected) {
    assertThat(pricing.discount(orderTotal)).isEqualByComparingTo(expected);
}

@ParameterizedTest
@ValueSource(strings = {"", " ", "abc", "+99450123"})
void invalidPhones(String phone) {
    assertThat(PhoneValidator.isValid(phone)).isFalse();
}

@ParameterizedTest
@EnumSource(value = OrderStatus.class, names = {"SHIPPED", "DELIVERED"})
void cannotCancel(OrderStatus status) { ... }

@ParameterizedTest
@MethodSource("transitions")
void stateMachine(OrderStatus from, OrderEvent event, OrderStatus to) { ... }
static Stream<Arguments> transitions() {
    return Stream.of(Arguments.of(NEW, PAY, PAID), Arguments.of(PAID, SHIP, SHIPPED));
}
```

## 4. Organizing tests

```java
@DisplayName("Order")
class OrderTest {
    @Nested @DisplayName("when NEW")
    class WhenNew {
        @Test void canBePaid() { }
        @Test void canBeCancelled() { }
    }
    @Nested @DisplayName("when SHIPPED")
    class WhenShipped {
        @Test void cannotBeCancelled() { }
    }
}

@Tag("slow") @Test void bigImport() { }
@Disabled("bug #123") @Test void flaky() { }
@Timeout(2) @Test void fastEnough() { }
@RepeatedTest(10) void concurrencySmoke() { }
```

## 5. Controlling time and randomness

```java
var service = new LoanService(fixed);
assertThat(service.nextPaymentDate()).isEqualTo(LocalDate.of(2026, 11, 15));
```

## 6. Test data builders

```java
public class OrderBuilder {
    private Customer customer = CustomerBuilder.aCustomer().build();
    private List<OrderLine> lines = new ArrayList<>();
    public static OrderBuilder anOrder() { return new OrderBuilder(); }
    public OrderBuilder withLine(String product, int qty, String price) { lines.add(new OrderLine(product, qty, new BigDecimal(price))); return this; }
    public Order build() { ... }
}

Order order = anOrder().withLine("Laptop", 1, "2400").withLine("Mouse", 2, "25").build();
```
Tests read like specifications; changes to constructors affect one place.
