## 1. Repositories

```java
public interface ProductRepository extends JpaRepository<Product, Long> { }
```
You get for free: `save`, `saveAll`, `findById`, `findAll`, `findAll(Pageable)`, `count`, `existsById`, `deleteById`, ...

## 2. Derived query methods

```java
Optional<Customer> findByEmail(String email);
boolean existsByEmail(String email);
List<Product> findByCategoryNameAndPriceLessThan(String category, BigDecimal max);
```

Spring parses the method name. Keep names short; for complex logic use `@Query`.

## 3. @Query

```java
@Query("SELECT o FROM Order o JOIN FETCH o.customer WHERE o.status = :status")
List<Order> findWithCustomer(@Param("status") OrderStatus status);

@Modifying
@Query("UPDATE Product p SET p.price = p.price * :factor WHERE p.category.id = :categoryId")
int changePrices(Long categoryId, BigDecimal factor);
```

## 6. Specifications (dynamic filters)

```java
public interface ProductRepository extends JpaRepository<Product, Long>, JpaSpecificationExecutor<Product> { }

public final class ProductSpecs {
    public static Specification<Product> nameContains(String text) {
        return (root, q, cb) -> text == null ? null : cb.like(cb.lower(root.get("name")), "%" + text.toLowerCase() + "%");
    }
    public static Specification<Product> priceBetween(BigDecimal min, BigDecimal max) {
        return (root, q, cb) -> {
            if (min == null && max == null) return null;
            if (min == null) return cb.le(root.get("price"), max);
            if (max == null) return cb.ge(root.get("price"), min);
            return cb.between(root.get("price"), min, max);
        };
    }
}

Page<Product> result = repo.findAll(
        Specification.where(nameContains(f.text())).and(priceBetween(f.min(), f.max())), pageable);
```

## 7. Service layer

```java
@Service
@Transactional(readOnly = true)
public class CatalogService {
    private final ProductRepository products;

    public CatalogService(ProductRepository products) { this.products = products; }

    public Page<ProductCard> search(ProductFilter filter, Pageable pageable) { ... }

    @Transactional
    public Product create(CreateProductCommand cmd) {
        if (products.existsBySku(cmd.sku())) throw new DuplicateSkuException(cmd.sku());
        return products.save(new Product(cmd.sku(), cmd.name(), cmd.price()));
    }
}
```
Don't put business logic in repositories; don't call repositories from controllers directly in bigger apps.
