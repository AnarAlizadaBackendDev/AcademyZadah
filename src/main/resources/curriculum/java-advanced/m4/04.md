## 1. application.yml

```yaml
server:
  port: 8080

spring:
  application:
    name: shop
  datasource:
    url: jdbc:postgresql://localhost:5432/shop
    username: shop
    password: ${DB_PASSWORD}          # from environment variable

shop:
  checkout:
    max-items: 50
    reservation-timeout: 15m
  payment:
    provider-url: https://sandbox.payments.example
    api-key: ${PAYMENT_API_KEY:dev-key}   # default value after ':'
```

## 2. Reading properties

### @Value (simple values)
```java
@Value("${shop.checkout.max-items}")
private int maxItems;
```

### @ConfigurationProperties ✅ (type-safe, grouped, validated)
```java
@ConfigurationProperties(prefix = "shop.checkout")
@Validated
public record CheckoutProperties(
        @Min(1) int maxItems,
        Duration reservationTimeout) { }

@SpringBootApplication
@ConfigurationPropertiesScan
public class ShopApplication { ... }

@Service
public class CheckoutService {
    private final CheckoutProperties props;
    public CheckoutService(CheckoutProperties props) { this.props = props; }
}
```
Relaxed binding: `max-items`, `maxItems`, `MAX_ITEMS` all map to `maxItems`.

## 3. Profiles

```yaml
# application.yml: common
spring:
  profiles:
    active: dev            # default for local runs
---
spring:
  config:
    activate:
      on-profile: dev
  jpa:
    show-sql: true
---
spring:
  config:
    activate:
      on-profile: prod
logging:
  level:
    root: warn
```
Or separate files: `application-dev.yml`, `application-prod.yml`.

Activate: `SPRING_PROFILES_ACTIVE=prod java -jar app.jar` or `--spring.profiles.active=prod`.

Beans per profile: `@Profile("dev")`.

## 4. Property source order (highest wins)

1. Command-line args `--server.port=9000`
2. Environment variables `SERVER_PORT=9000`
3. `application-{profile}.yml`
4. `application.yml`
5. Defaults in code

This is how the **same jar** runs in dev, test and prod: the 12-factor app principle "config in the environment".

## 5. Secrets

- ❌ Never commit passwords/API keys to Git.
- ✅ Environment variables, `.env` files ignored by Git (local), secret managers in production (Vault, GCP Secret Manager, Kubernetes Secrets, Railway variables).

```gitignore

application-local.yml
```
