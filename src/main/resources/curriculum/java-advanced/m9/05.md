> **Goal:** start the final project: choose, specify and design a job-ready backend system.
> **Duration:** 120 min

## 1. Purpose of the final project

Your final project is your **portfolio centerpiece** and your best interview story. It should show that you can build, test, secure, deploy and operate a real backend system.

## 2. Project options

| Project | Highlights |
|---|---|
| **Payment-link platform** | merchants, links, payments via mock processor, webhooks, dashboard, idempotency |
| **Digital wallet** | accounts, top-ups, P2P transfers, limits, ledger (double-entry), statements |
| **Food delivery** | restaurants, menus, orders, couriers, real-time status, saga |
| **Learning platform** | courses, lessons, enrollments, drip content, progress (like this website!) |
| **Clinic booking** | doctors, slots, bookings without double-booking, reminders |
| Your own idea | must be approved by the mentor |

## 3. Mandatory technical scope

- Java 21, Spring Boot 3, PostgreSQL, Flyway
- ≥ 2 services **or** a well-structured modular monolith (justify)
- REST API with OpenAPI docs, validation, ProblemDetail errors
- Security: JWT/Keycloak, roles, ownership checks
- At least one async flow with Kafka (or RabbitMQ) + outbox/idempotency
- Redis cache or rate limiting
- Tests: unit, slice, Testcontainers integration, 1 journey test; ≥ 70% branch coverage on business logic
- Docker Compose for local run
- CI pipeline; deployment to a public URL (Railway/Cloud Run/K8s)
- Observability: health, metrics, structured logs with trace ids

## 5. Planning in sprints

| Week | Focus |
|---|---|
| 1 | spec, skeleton, CI, Compose, auth |
| 2 | core domain + APIs + tests |
| 3 | async flows, cache, resilience |
| 4 | deployment, observability, polishing, demo prep |

Use GitHub Issues/Projects: one issue per user story; PRs reference issues.

## 6. Hands-on (in class)

1. Choose a project and pitch it in 2 minutes.
2. Write user stories (≥ 15) and prioritize: must/should/could.
3. Draw architecture and ERD; get mentor feedback.
4. Create the repository with CI and the skeleton.

## 7. Interview tip

Prepare to answer: "Tell me about a project you built." Structure: problem → architecture → hardest technical challenge → how you solved it → results/learnings.
