## 1. Microservices talk over HTTP

Your shop needs exchange rates, a payment provider, an SMS gateway... Calling them correctly (timeouts, errors, retries) is a core backend skill.

## 2. RestClient (Spring 6.1+): synchronous, modern

```java
@Configuration
class HttpClientsConfig {
    @Bean
    RestClient ratesClient(RestClient.Builder builder, RatesProperties props) {
        var factory = new JdkClientHttpRequestFactory(HttpClient.newBuilder()
                .connectTimeout(Duration.ofSeconds(2)).build());
        factory.setReadTimeout(Duration.ofSeconds(3));
        return builder.baseUrl(props.baseUrl())
                      .requestFactory(factory)
                      .defaultHeader("X-Api-Key", props.apiKey())
                      .build();
    }
}

@Component
class RatesClient {
    private final RestClient client;
    RatesClient(RestClient ratesClient) { this.client = ratesClient; }

    public BigDecimal rate(String from, String to) {
        RateResponse r = client.get()
                .uri("/rates?from={from}&to={to}", from, to)
                .retrieve()
                .onStatus(HttpStatusCode::is4xxClientError, (req, res) -> {
                    throw new RatesClientException("Bad request: " + res.getStatusCode());
                })
                .body(RateResponse.class);
        return r.rate();
    }
}
```
⚠️ Always set **timeouts**: a hanging dependency without timeouts blocks your threads until the whole service dies.

## 3. HTTP interfaces (declarative, Spring 6)

```java
public interface PaymentProviderApi {
    @PostExchange("/payments")
    PaymentProviderResponse create(@RequestBody PaymentProviderRequest request,
                                   @RequestHeader("Idempotency-Key") String key);

    @GetExchange("/payments/{id}")
    PaymentProviderResponse get(@PathVariable String id);
}

@Bean
PaymentProviderApi paymentProviderApi(RestClient paymentRestClient) {
    return HttpServiceProxyFactory.builderFor(RestClientAdapter.create(paymentRestClient))
            .build().createClient(PaymentProviderApi.class);
}
```

## 4. OpenFeign (Spring Cloud)

```java
@FeignClient(name = "sms", url = "${sms.url}")
public interface SmsClient {
    @PostMapping("/send")
    void send(@RequestBody SmsRequest request);
}
```
Very common in existing microservice projects.

## 5. WebClient: reactive / non-blocking

```java
Mono<RateResponse> mono = webClient.get().uri("/rates?from=USD&to=AZN").retrieve().bodyToMono(RateResponse.class);
```
Use in reactive (WebFlux) apps. In MVC apps with virtual threads, `RestClient` is simpler.

## 6. Resilience basics

| Problem | Solution |
|---|---|
| slow dependency | timeouts |
| transient failures (502/503, timeouts) | **retry** with backoff (only idempotent calls!) |
| dependency down for minutes | **circuit breaker** (month 8) + fallback/cache |
| duplicate side effects on retry | idempotency keys |

```java
@Retryable(retryFor = {ResourceAccessException.class}, maxAttempts = 3, backoff = @Backoff(delay = 200, multiplier = 2))
public BigDecimal rate(String from, String to) { ... }

@Recover
public BigDecimal fallback(ResourceAccessException e, String from, String to) {
    return cache.lastKnownRate(from, to);
}
```

## 7. Testing HTTP clients

- `MockRestServiceServer` for RestClient.
- **WireMock** for realistic stubs (delays, errors).
```java
stubFor(get(urlPathEqualTo("/rates")).willReturn(aResponse().withFixedDelay(5000)));   // test timeouts
```
