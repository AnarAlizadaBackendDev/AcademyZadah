> **Goal:** implement REST endpoints in Spring MVC with clean DTOs.
> **Duration:** 120 min

## 1. A REST controller

```java
@RestController
@RequestMapping("/api/products")
public class ProductController {

    private final CatalogService catalog;

    public ProductController(CatalogService catalog) {
        this.catalog = catalog;
    }

    @GetMapping
    public Page<ProductResponse> list(@RequestParam(required = false) String category,
                                      @PageableDefault(size = 20, sort = "name") Pageable pageable) {
        return catalog.list(category, pageable);
    }

    @GetMapping("/{id}")
    public ProductResponse get(@PathVariable Long id) {
        return catalog.get(id);
    }

    @PostMapping
    public ResponseEntity<ProductResponse> create(@RequestBody CreateProductRequest request) {
        ProductResponse created = catalog.create(request);
        URI location = ServletUriComponentsBuilder.fromCurrentRequest()
                .path("/{id}").buildAndExpand(created.id()).toUri();
        return ResponseEntity.created(location).body(created);          // 201 + Location
    }

    @PutMapping("/{id}")
    public ProductResponse update(@PathVariable Long id, @RequestBody UpdateProductRequest request) {
        return catalog.update(id, request);
    }

    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)
    public void delete(@PathVariable Long id) {
        catalog.delete(id);
    }
}
```

## 2. Request data

| Annotation | From | Example |
|---|---|---|
| `@PathVariable` | URL path | `/products/{id}` |
| `@RequestParam` | query string | `?category=x` |
| `@RequestBody` | JSON body | create/update |
| `@RequestHeader` | header | `Idempotency-Key` |
| `@ModelAttribute` | query params → object | filters |

```java
public record ProductFilter(String text, BigDecimal minPrice, BigDecimal maxPrice, Long categoryId) { }

@GetMapping("/search")
public Page<ProductResponse> search(ProductFilter filter, Pageable pageable) { ... }   // binds ?text=..&minPrice=..
```

## 3. DTOs as records

```java
public record CreateProductRequest(String sku, String name, BigDecimal price, Long categoryId) { }

public record ProductResponse(Long id, String sku, String name, BigDecimal price, String categoryName) {
    public static ProductResponse from(Product p) {
        return new ProductResponse(p.getId(), p.getSku(), p.getName(), p.getPrice(), p.getCategory().getName());
    }
}
```
Separate request and response DTOs: they evolve differently (id/createdAt only in responses).

## 4. JSON with Jackson

Spring Boot configures Jackson automatically.
```yaml
spring:
  jackson:
    default-property-inclusion: non_null
    serialization:
      write-dates-as-timestamps: false
```
```java
@JsonProperty("created_at") Instant createdAt      // rename a field
@JsonIgnore String internalNote                     // never serialize
@JsonFormat(shape = JsonFormat.Shape.STRING) BigDecimal amount   // money as string
```

## 5. ResponseEntity

Full control over status/headers:
```java
return ResponseEntity.ok(body);
return ResponseEntity.status(HttpStatus.ACCEPTED).header("Retry-After", "5").body(body);
return ResponseEntity.noContent().build();
return ResponseEntity.notFound().build();
```
