> **Goal:** validate API input with Bean Validation and custom validators.
> **Duration:** 120 min

## 1. Never trust input

Every request field can be missing, empty, huge or malicious. Validate at the **API boundary**, and keep invariants in the domain.

```groovy
implementation 'org.springframework.boot:spring-boot-starter-validation'
```

## 2. Constraint annotations

```java
public record CreateCustomerRequest(
        @NotBlank @Size(max = 120) String fullName,
        @NotBlank @Email String email,
        @Pattern(regexp = "\\+994(50|51|55|70|77|99|10)\\d{7}", message = "must be a valid AZ mobile number") String phone,
        @NotNull @Past LocalDate birthDate,
        @Valid AddressRequest address) { }        // validate nested object

public record AddressRequest(@NotBlank String city, @NotBlank String street, @Size(max = 10) String zip) { }

public record PlaceOrderRequest(
        @NotNull Long customerId,
        @NotEmpty @Size(max = 50) List<@Valid OrderLineRequest> items) { }

public record OrderLineRequest(@NotNull Long productId, @Positive @Max(100) int quantity) { }
```

| Annotation | Checks |
|---|---|
| `@NotNull` | not null |
| `@NotEmpty` | not null and not empty (string/collection) |
| `@NotBlank` | string has non-whitespace text |
| `@Size(min,max)` | length / size |
| `@Min` `@Max` `@Positive` `@PositiveOrZero` | numbers |
| `@DecimalMin("0.01")` `@Digits(integer=15, fraction=2)` | decimals |
| `@Email` `@Pattern` | format |
| `@Past` `@Future` | dates |

## 3. Trigger validation

```java
@PostMapping
public ResponseEntity<CustomerResponse> create(@Valid @RequestBody CreateCustomerRequest request) { ... }

@GetMapping
public Page<ProductResponse> list(@RequestParam @Min(0) int page, @RequestParam @Max(100) int size) { ... }
// method-level validation of params requires @Validated on the controller class
```
On failure Spring throws `MethodArgumentNotValidException` → 400 (we format the response in the next lesson).

## 4. Custom validator

```java
@Target({ElementType.FIELD, ElementType.RECORD_COMPONENT})
@Retention(RetentionPolicy.RUNTIME)
@Constraint(validatedBy = IbanValidator.class)
public @interface ValidIban {
    String message() default "must be a valid IBAN";
    Class<?>[] groups() default {};
    Class<? extends Payload>[] payload() default {};
}

public class IbanValidator implements ConstraintValidator<ValidIban, String> {
    @Override
    public boolean isValid(String value, ConstraintValidatorContext ctx) {
        if (value == null) return true;                         // combine with @NotNull if required
        String iban = value.replace(" ", "").toUpperCase();
        if (!iban.matches("[A-Z]{2}\\d{2}[A-Z0-9]{11,30}")) return false;
        String rearranged = iban.substring(4) + iban.substring(0, 4);
        StringBuilder numeric = new StringBuilder();
        for (char ch : rearranged.toCharArray()) numeric.append(Character.getNumericValue(ch));
        return new BigInteger(numeric.toString()).mod(BigInteger.valueOf(97)).intValue() == 1;   // mod-97 check
    }
}

public record TransferRequest(@ValidIban @NotNull String toIban, @DecimalMin("0.01") BigDecimal amount) { }
```

## 5. Groups (create vs update)

```java
public interface OnCreate { }
public record ProductRequest(@Null(groups = OnCreate.class) Long id, @NotBlank String name) { }

@PostMapping
public ProductResponse create(@Validated(OnCreate.class) @RequestBody ProductRequest r) { ... }
```
Often simpler: separate DTOs for create and update.

## 6. Validation layers

| Layer | Validates |
|---|---|
| API (Bean Validation) | format, required fields, sizes |
| Service | business rules needing data (email unique, stock available) |
| Domain | invariants (balance never negative) |
| Database | constraints (last line of defence) |
